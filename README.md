# lundq.no

Treningsplanlegger hostet på [lundq.no](https://lundq.no) via GitHub Pages.

## Oppsett

- **Domene:** lundq.no (registrert hos Domeneshop, DNS peker til GitHub Pages)
- **Hosting:** GitHub Pages (gratis)
- **Lagring:** JSONBin.io (gratis JSON-database)

## Bruk

Alle kan besøke siden og prøve planleggeren. For å lagre endringer kreves en API-nøkkel.
